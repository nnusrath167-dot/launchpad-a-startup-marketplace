# LaunchPad MRECW

LaunchPad MRECW is a student startup marketplace and innovation hub for Malla Reddy Engineering College for Women. The frontend is built with HTML, CSS, and vanilla JavaScript; the Python HTTP API can use local SQLite or Supabase PostgreSQL.

## Requirements

- Python 3.10 or newer
- A modern browser

SQLite mode uses only the Python standard library. Supabase PostgreSQL mode dependencies are listed in `backend/requirements.txt`.

## Run locally

From the project root in PowerShell:

```powershell
python backend\server.py
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000). Keep the server running while using the site. Stop it with `Ctrl+C`.

Without `backend/.env`, the server uses `launchpad.db`, preserving existing records and seeding demo teams when missing. To use Supabase PostgreSQL, first apply [`supabase/schema.sql`](./supabase/schema.sql), then follow the [Supabase setup guide](./supabase/README.md) to configure `backend/.env`, the frontend public Auth key, and backend dependencies.

## API

- `GET /api/health` — server readiness check
- `GET /api/startups` — list persisted startups
- `POST /api/startups` — publish a startup
- `POST /api/applications` — apply to join a persisted startup

In local SQLite mode, there is no user authentication. Supabase mode adds account registration/sign-in and authenticated startup/application writes. Co-founder, mentor, spotlight, leaderboard, and AI Lab content is sample/demo content; no external AI service is configured. Supabase starts with no sample startup records.

The marketplace supports searching startup names, teams, descriptions, skills, departments, and stages. Use the **Saved** filter to revisit startups bookmarked in the current browser.

The project includes a Supabase PostgreSQL schema in [`supabase/schema.sql`](./supabase/schema.sql). The frontend uses Supabase Auth, while startup and application data requests go through the Python API. Configure the private database URL and Auth verification settings in `backend/.env`; only the public anon/publishable key belongs in `frontend/js/supabase-config.js`. Follow [supabase/README.md](./supabase/README.md). Never put a database password or service-role key in the browser or GitHub.

## Uploading to GitHub

- `backend/.env` and local SQLite databases are excluded by `.gitignore`; keep them that way.
- `backend/.env.example` contains placeholders for local setup and is safe to upload.
- The Supabase publishable/anon key in `frontend/js/supabase-config.js` is designed to be public. Never put a database password, service-role key, or other secret there.
- Review the sample/demo content before presenting the site as an official live MRECW service.

Uploading this repository to GitHub does not deploy the site. GitHub Pages cannot run the Python API; deploy the Python backend to a Python-capable host, set its private environment variables there, and serve the frontend and `/api` on the same origin. Then configure the deployed origin in Supabase Auth URL settings.

See [backend/README.md](./backend/README.md) and [frontend/README.md](./frontend/README.md) for component-specific notes.

def connect_database():
    if DATABASE_URL:
        if psycopg is None:
            raise RuntimeError(
                "PostgreSQL mode requires the backend requirements. Install backend/requirements.txt."
            )
        return psycopg.connect(DATABASE_URL, row_factory=dict_row)

    connection = sqlite3.connect(DATABASE, timeout=10)
    connection.row_factory = sqlite3.Row
    connection.execute("PRAGMA foreign_keys = ON")
    return connection

def category_slug(category):
    normalized = category.strip().casefold()
    return CATEGORY_SLUGS.get(normalized, normalized.replace(" ", "-"))

def required_text(payload, key, maximum):
    value = payload.get(key)
    if not isinstance(value, str):
        raise ValueError(f"{key} must be a text value.")
    value = value.strip()
    if not value or len(value) > maximum:
        raise ValueError(f"{key} must be between 1 and {maximum} characters.")
    return value


def set_postgres_request_role(connection, role, user=None):
    if role not in {"anon", "authenticated"}:
        raise ValueError("Invalid database request role.")
    connection.execute(f"SET LOCAL ROLE {role}")
    if user:
        connection.execute(
            "SELECT set_config('request.jwt.claim.sub', %s, true)",
            (user["id"],),
        )


class LaunchPadHandler(SimpleHTTPRequestHandler):
    def __init__(self, *args, **kwargs):
        super().__init__(*args, directory=str(FRONTEND), **kwargs)

    def send_json(self, status, payload):
        body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", "no-store")
        self.end_headers()
        self.wfile.write(body)

    def read_json(self):
        try:
            length = int(self.headers.get("Content-Length", "0"))
        except ValueError as error:
            raise ValueError("Invalid request body length.") from error
        if length < 1 or length > 16_384:
            raise ValueError("Request body must be between 1 and 16384 bytes.")
        try:
            payload = json.loads(self.rfile.read(length))
        except (json.JSONDecodeError, UnicodeDecodeError) as error:
            raise ValueError("Request body must contain valid JSON.") from error
        if not isinstance(payload, dict):
            raise ValueError("Request body must be a JSON object.")
        return payload

    def authenticated_user(self):
        authorization = self.headers.get("Authorization", "")
        scheme, separator, token = authorization.partition(" ")
        if not separator or scheme.casefold() != "bearer" or not token.strip():
            raise PermissionError("Sign in is required for this action.")
        if not SUPABASE_URL or not SUPABASE_ANON_KEY:
            raise RuntimeError(
                "Supabase authentication is not configured on the backend."
            )

        request = Request(
            f"{SUPABASE_URL}/auth/v1/user",
            headers={
                "apikey": SUPABASE_ANON_KEY,
                "Authorization": f"Bearer {token.strip()}",
                "Accept": "application/json",
            },
        )
        try:
            with urlopen(request, timeout=10) as response:
                user = json.loads(response.read())
        except HTTPError as error:
            if error.code in {401, 403}:
                raise PermissionError("Your session is invalid or expired. Sign in again.") from error
            raise RuntimeError("Could not verify the Supabase session.") from error
        except (URLError, TimeoutError, json.JSONDecodeError) as error:
            raise RuntimeError("Could not verify the Supabase session.") from error

        if not isinstance(user, dict) or not user.get("id"):
            raise PermissionError("Your session is invalid. Sign in again.")
        return user

    def do_GET(self):
        path = urlparse(self.path).path
        if path == "/api/health":
            if DATABASE_URL:
                try:
                    with connect_database() as connection:
                        connection.execute("SELECT 1")
                except (RuntimeError, *DATABASE_ERRORS) as error:
                    logging.error("Health check database failure (%s)", type(error).__name__)
                    self.send_json(503, {"status": "error", "error": "Database is unavailable."})
                    return
            self.send_json(200, {"status": "ok"})
            return
        if path == "/api/startups":
            try:
                with connect_database() as connection:
                    if DATABASE_URL:
                        set_postgres_request_role(connection, "anon")
                    rows = connection.execute(
                        "SELECT * FROM startups ORDER BY created_at DESC, id DESC"
                    ).fetchall()
                self.send_json(200, [startup_response(row) for row in rows])
            except RuntimeError as error:
                logging.error("Could not retrieve startups (%s)", type(error).__name__)
                self.send_json(500, {"error": "Could not retrieve startups. Check the database configuration."})
            except DATABASE_ERRORS as error:
                logging.error("Could not retrieve startups (%s)", type(error).__name__)
                self.send_json(500, {"error": "Could not retrieve startups."})
            return
        if path.startswith("/api/"):
            self.send_json(404, {"error": "API route not found."})
            return
        if path == "/":
            self.path = "/index.html"
        super().do_GET()

    def do_POST(self):
        path = urlparse(self.path).path
        if path not in {"/api/startups", "/api/applications"}:
            self.send_json(404, {"error": "API route not found."})
            return
        try:
            payload = self.read_json()
            user = self.authenticated_user() if DATABASE_URL else None
            if path == "/api/startups":
                self.create_startup(payload, user)
            else:
                self.create_application(payload, user)
        except PermissionError as error:
            self.send_json(401, {"error": str(error)})
        except ValueError as error:
            self.send_json(400, {"error": str(error)})
        except RuntimeError as error:
            logging.error("Request configuration or authentication failed (%s)", type(error).__name__)
            self.send_json(503, {"error": str(error)})
        except DATABASE_INTEGRITY_ERRORS:
            self.send_json(400, {"error": "The submitted data could not be saved."})
        except DATABASE_ERRORS as error:
            logging.error("Database request failed (%s)", type(error).__name__)
            self.send_json(500, {"error": "The server could not save your request."})

    def create_startup(self, payload, user=None):
        name = required_text(payload, "name", 100)
        team_name = required_text(payload, "teamName", 100)
        tagline = required_text(payload, "tagline", 300)
        looking_for = required_text(payload, "lookingFor", 150)
        category = payload.get("category")
        department = payload.get("department")
        if not isinstance(category, str) or category not in CATEGORIES:
            raise ValueError("Choose a valid startup category.")
        if not isinstance(department, str) or department not in DEPARTMENTS:
            raise ValueError("Choose a valid MRECW department.")

        if DATABASE_URL and not user:
            raise PermissionError("Sign in is required to publish a startup.")

        user_metadata = user.get("user_metadata") or {} if user else {}
        founder_name = (
            required_text(user_metadata, "full_name", 100)
            if user_metadata.get("full_name")
            else (user.get("email") or "MRECW Student" if user else "MRECW Student")
        )
        founder_major = user_metadata.get("major") or user_metadata.get("department") or "MRECW Student"

        with connect_database() as connection:
            if DATABASE_URL:
                set_postgres_request_role(connection, "authenticated", user)
                row = connection.execute(
                    """
                    INSERT INTO startups (
                        founder_id, name, team_name, tagline, category, department,
                        looking_for, founder_name, founder_major, founder_avatar,
                        banner, stage, problem, description
                    ) VALUES (
                        %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, %s, 'Prototype',
                        %s, %s
                    )
                    RETURNING *
                    """,
                    (
                        user["id"],
                        name,
                        team_name,
                        tagline,
                        category,
                        department,
                        looking_for,
                        founder_name,
                        founder_major,
                        DEFAULT_AVATAR,
                        DEFAULT_BANNER,
                        "Student innovation challenge entry at MRECW.",
                        "Prototype submitted by an MRECW student team.",
                    ),
                ).fetchone()
            else:
                cursor = connection.execute(
                    """
                    INSERT INTO startups (
                        name, team_name, tagline, category, department, looking_for,
                        founder_name, stage, problem, description, banner, founder_major,
                        founder_avatar
                    ) VALUES (?, ?, ?, ?, ?, ?, ?, 'Prototype', ?, ?, ?, ?, ?)
                    """,
                    (
                        name,
                        team_name,
                        tagline,
                        category,
                        department,
                        looking_for,
                        founder_name,
                        "Student innovation challenge entry at MRECW.",
                        "Prototype submitted by an MRECW student team.",
                        DEFAULT_BANNER,
                        founder_major,
                        DEFAULT_AVATAR,
                    ),
                )
                row = connection.execute(
                    "SELECT * FROM startups WHERE id = ?", (cursor.lastrowid,)
                ).fetchone()
        self.send_json(201, startup_response(row))

    def create_application(self, payload, user=None):
        startup_id = payload.get("startupId")
        if not isinstance(startup_id, str):
            raise ValueError("Choose a startup before applying.")
        match = re.fullmatch(r"startup-(\d+)", startup_id)
        if not match:
            raise ValueError("This startup is not available for applications. Refresh and try again.")
        numeric_id = int(match.group(1))
        message = required_text(payload, "message", 1000)
        if DATABASE_URL:
            if not user:
                raise PermissionError("Sign in is required to submit an application.")
            metadata = user.get("user_metadata") or {}
            applicant_name = metadata.get("full_name") or user.get("email") or "MRECW Student"
            email = user.get("email") or ""
        else:
            applicant_name = required_text(payload, "applicantName", 100)
            email = required_text(payload, "email", 254)
            if not re.fullmatch(r"[^@\s]+@[^@\s]+\.[^@\s]+", email):
                raise ValueError("Enter a valid email address.")

        with connect_database() as connection:
            if DATABASE_URL:
                set_postgres_request_role(connection, "authenticated", user)
                startup = connection.execute(
                    "SELECT id FROM startups WHERE id = %s", (numeric_id,)
                ).fetchone()
            else:
                startup = connection.execute(
                    "SELECT id FROM startups WHERE id = ?", (numeric_id,)
                ).fetchone()
            if not startup:
                self.send_json(404, {"error": "That startup could not be found."})
                return
            if DATABASE_URL:
                row = connection.execute(
                    """
                    INSERT INTO applications (
                        startup_id, applicant_id, applicant_name, email, message
                    ) VALUES (%s, %s, %s, %s, %s)
                    """,
                    (numeric_id, user["id"], applicant_name, email, message),
                )
                application_id = connection.execute(
                    "SELECT currval('public.applications_id_seq') AS id"
                ).fetchone()["id"]
            else:
                cursor = connection.execute(
                    """
                    INSERT INTO applications (startup_id, applicant_name, email, message)
                    VALUES (?, ?, ?, ?)
                    """,
                    (numeric_id, applicant_name, email, message),
                )
                application_id = cursor.lastrowid
        self.send_json(201, {"id": application_id, "status": "submitted"})


if __name__ == "__main__":
    logging.basicConfig(level=logging.INFO, format="%(asctime)s %(levelname)s %(message)s")

# Backend

`server.py` runs the website API. Without `backend/.env` database settings it serves the static frontend with the local SQLite database, preserves existing records, and seeds demo startup teams when they are not already present. With `DATABASE_URL` configured it uses Supabase PostgreSQL, validates the Supabase schema at startup, and verifies Supabase Auth access tokens for write requests.

From the project root:

```powershell
python backend\server.py
```

The service listens on `127.0.0.1:8000` by default. `launchpad.db` lives in the project root. Set `HOST` or `PORT` environment variables to override the listener.

## Supabase PostgreSQL mode

1. Apply `supabase/schema.sql` in the Supabase SQL Editor.
2. From the project root, copy `backend\.env.example` to `backend\.env` and fill in the private PostgreSQL connection string, Supabase Project URL, and public anon/publishable key. Never commit `.env` or expose the database password.
3. Add the Supabase Project URL and public anon/publishable key to `frontend/js/supabase-config.js` for browser authentication.
4. Install dependencies from the project root with `python -m pip install -r backend\requirements.txt`.
5. Run `python backend\server.py`.

The frontend continues calling the same `/api` routes. In PostgreSQL mode, the API validates bearer tokens with Supabase Auth, then executes database requests as the PostgreSQL `anon` or `authenticated` role with the verified user ID set for RLS. If `DATABASE_URL` is absent, SQLite mode remains available for local development.

Do not run with a placeholder or empty PostgreSQL connection string. The API does not automatically apply `schema.sql` or migrate existing SQLite rows.

## Routes

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/health` | Check server readiness |
| GET | `/api/startups` | Read startup records |
| POST | `/api/startups` | Validate and persist a startup |
| POST | `/api/applications` | Validate and persist an application |

SQLite mode is intended for local development and does not provide authentication. Supabase mode verifies signed-in users for write requests. Production hosting still needs HTTPS, secret environment variables, and deployment hardening; the AI Lab remains demo content.

# Frontend

The frontend is a static, responsive LaunchPad MRECW site:

- `index.html` contains the page structure and dialogs.
- `css/styles.css` contains the supplied visual design.
- `js/app.js` handles navigation, filtering, rendering, API requests, and saved startups.

Serve it through the backend with `python backend\server.py` from the project root. The JavaScript uses same-origin `/api` endpoints in local mode, so opening `index.html` directly as a local file will not enable publishing or applications.

Startup bookmarks are saved in the current browser using local storage and can be filtered with the **Saved** chip. They are browser-specific and are not synced between devices or accounts.

To enable Supabase mode, run `supabase/schema.sql` in your Supabase project's SQL Editor and set the project URL and public anon/publishable key in `js/supabase-config.js`. The browser uses Supabase Auth; startup and application data requests go through the Python API, which verifies access tokens and applies PostgreSQL roles so database RLS policies are enforced. Leave the Supabase settings blank to use local SQLite. Never use a Supabase service-role/secret key in the frontend.

The frontend and Python API must be served from the same origin because API requests use relative `/api` paths. GitHub Pages alone cannot host the Python API. See the root README and `supabase/README.md` for deployment and configuration details.

    function switchTab(tab) {
      appState.activeTab = tab;
      document.querySelectorAll('.app-view-panel').forEach(p => p.classList.add('hidden'));
      const active = document.getElementById(`view-${tab}`);
      if (active) active.classList.remove('hidden');
      document.querySelectorAll('.nav-link').forEach(link => {
        link.classList.toggle('active', link.getAttribute('data-tab') === tab);
      });
      window.scrollTo({ top: 0, behavior: 'smooth' });
      if (tab === 'home') renderMarketplace();
      else if (tab === 'cofounders') renderCoFounders();
      else if (tab === 'ailab') renderAILab();
      else if (tab === 'mentors') renderMentors();
    }

    function openModal(id) { document.getElementById(id).classList.remove('hidden'); }
    function closeModal(id) { document.getElementById(id).classList.add('hidden'); }

    function showToast(msg) {
      const c = document.getElementById('toast-container');
      const t = document.createElement('div');
      t.className = 'toast-item';
      t.textContent = msg;
      c.appendChild(t);
      setTimeout(() => t.remove(), 3500);
    }

    function escapeHtml(value) {
      return String(value ?? '').replace(/[&<>"']/g, character => ({
        '&': '&amp;',
        '<': '&lt;',
        '>': '&gt;',
        '"': '&quot;',
        "'": '&#39;'
      })[character]);
    }

    async function requestJson(path, options = {}) {
      const headers = { 'Content-Type': 'application/json', ...options.headers };
      if (appState.authSession?.access_token) {
        headers.Authorization = `Bearer ${appState.authSession.access_token}`;
      }
      const response = await fetch(path, {
        ...options,
        headers
      });
      const result = await response.json();
      if (!response.ok) throw new Error(result.error || 'The request could not be completed.');
      return result;
    }

    function supabaseIsConfigured() {
      return Boolean(appState.supabaseClient);
    }

    async function initializeSupabase() {
      const config = window.LAUNCHPAD_SUPABASE_CONFIG;
      if (!config || !config.url || !config.anonKey) return;
      appState.startups = [];
      renderMarketplace();
      if (!window.supabase?.createClient) {
        throw new Error('Supabase client library did not load. Check your internet connection and reload.');
      }

      appState.supabaseClient = window.supabase.createClient(config.url, config.anonKey);
      document.getElementById('auth-nav-button').classList.remove('hidden');
      appState.supabaseClient.auth.onAuthStateChange((_event, session) => {
        appState.authSession = session || null;
        appState.authUser = session?.user || null;
        updateAuthNavigation();
      });
      const { data, error } = await appState.supabaseClient.auth.getSession();
      if (error) throw error;
      appState.authSession = data.session || null;
      appState.authUser = data.session?.user || null;
      updateAuthNavigation();
    }

    function updateAuthNavigation() {
      const button = document.getElementById('auth-nav-button');
      if (!button) return;
      button.textContent = appState.authUser ? 'Sign out' : 'Sign in';
      button.title = appState.authUser?.email || 'Sign in to your MRECW account';
    }

    function handleAuthButton() {
      if (!supabaseIsConfigured()) return;
      if (appState.authUser) {
        appState.supabaseClient.auth.signOut()
          .then(({ error }) => {
            if (error) throw error;
            appState.authUser = null;
            appState.authSession = null;
            appState.pendingAuthAction = null;
            updateAuthNavigation();
            showToast('You have been signed out.');
          })
          .catch(error => showToast(`Could not sign out: ${error.message}`));
        return;
      }
      openModal('modal-auth');
    }

    function handleLaunchStartup() {
      if (supabaseIsConfigured() && !appState.authUser) {
        appState.pendingAuthAction = 'publish';
        showToast('Sign in before publishing a startup.');
        openModal('modal-auth');
        return;
      }
      openModal('modal-post-startup');
    }

    function updateAuthFields() {
      const signup = document.getElementById('auth-mode').value === 'signup';
      const fields = document.getElementById('auth-signup-fields');
      const name = document.getElementById('auth-name');
      const password = document.getElementById('auth-password');
      fields.classList.toggle('hidden', !signup);
      name.required = signup;
      password.autocomplete = signup ? 'new-password' : 'current-password';
      document.getElementById('auth-submit').textContent = signup ? 'Create account' : 'Sign in';
    }

    async function handleAuthSubmit(event) {
      event.preventDefault();
      if (!supabaseIsConfigured()) {
        showToast('Supabase is not configured. Follow the Supabase setup guide.');
        return;
      }

      const email = document.getElementById('auth-email').value.trim();
      const password = document.getElementById('auth-password').value;
      const signup = document.getElementById('auth-mode').value === 'signup';
      const submit = document.getElementById('auth-submit');
      submit.disabled = true;

      try {
        let result;
        if (signup) {
          result = await appState.supabaseClient.auth.signUp({
            email,
            password,
            options: {
              data: {
                full_name: document.getElementById('auth-name').value.trim(),
                department: document.getElementById('auth-department').value,
                major: document.getElementById('auth-major').value.trim()
              }
            }
          });
        } else {
          result = await appState.supabaseClient.auth.signInWithPassword({ email, password });
        }

        if (result.error) throw result.error;
        if (signup && !result.data.session) {
          closeModal('modal-auth');
          showToast('Account created. Check your email to confirm it, then sign in.');
          return;
        }

        appState.authSession = result.data.session || null;
        appState.authUser = result.data.user;
        updateAuthNavigation();
        closeModal('modal-auth');
        document.querySelector('#modal-auth form').reset();
        updateAuthFields();
        showToast(signup ? 'Your account is ready.' : 'Welcome back.');
        if (appState.pendingAuthAction === 'publish') {
          appState.pendingAuthAction = null;
          openModal('modal-post-startup');
        } else if (appState.pendingAuthAction === 'apply') {
          appState.pendingAuthAction = null;
          openModal('modal-join-team');
        }
      } catch (error) {
        showToast(`Authentication failed: ${error.message}`);
      } finally {
        submit.disabled = false;
      }
    }

    async function loadStartups() {
      const records = await requestJson('/api/startups');
      if (!Array.isArray(records)) throw new Error('The server returned an invalid startup list.');
      appState.startups = records;
      renderMarketplace();
    }

    function loadSavedStartups() {
      try {
        const savedIds = JSON.parse(localStorage.getItem('launchpad-saved-startups') || '[]');
        if (!Array.isArray(savedIds) || !savedIds.every(id => typeof id === 'string')) {
          throw new Error('Saved startup data has an unexpected format.');
        }
        appState.savedIds = new Set(savedIds);
      } catch (error) {
        console.error('Could not load saved startups from browser storage:', error);
        showToast('Saved startups could not be loaded from this browser.');
      }
    }

    function toggleSavedStartup(id) {
      const nextSavedIds = new Set(appState.savedIds);
      if (nextSavedIds.has(id)) nextSavedIds.delete(id);
      else nextSavedIds.add(id);

      try {
        localStorage.setItem('launchpad-saved-startups', JSON.stringify([...nextSavedIds]));
      } catch (error) {
        console.error('Could not save startup in browser storage:', error);
        showToast('Could not update saved startups in this browser.');
        return;
      }

      appState.savedIds = nextSavedIds;
      renderMarketplace();
      showToast(nextSavedIds.has(id) ? 'Startup saved to your list.' : 'Startup removed from your saved list.');
    }

    }

    (function initAurora() {
      const canvas = document.getElementById('aurora-canvas');
      if (!canvas) return;
      const ctx = canvas.getContext('2d');
      let w, h, step = 0;
      function resize() { w = canvas.width = canvas.offsetWidth; h = canvas.height = canvas.offsetHeight; }
      window.addEventListener('resize', resize);
      resize();

      function loop() {
        step += 0.015;
        ctx.clearRect(0, 0, w, h);
        for (let i = 0; i < 6; i++) {
          ctx.beginPath();
          const grad = ctx.createLinearGradient(0, 0, w, 0);
          grad.addColorStop(0, 'rgba(59, 130, 246, 0.1)');
          grad.addColorStop(0.4, 'rgba(139, 92, 246, 0.45)');
          grad.addColorStop(0.7, 'rgba(6, 182, 212, 0.4)');
          grad.addColorStop(1, 'rgba(236, 72, 153, 0.25)');
          ctx.strokeStyle = grad;
          ctx.lineWidth = 1.8;
          for (let x = 0; x <= w; x += 14) {
            const y = (h * 0.7) + (i * 7) + Math.sin(x * 0.003 + step + i * 0.25) * 35;
            if (x === 0) ctx.moveTo(x, y); else ctx.lineTo(x, y);
          }
          ctx.stroke();
        }
        requestAnimationFrame(loop);
      }
      loop();
    })();

-- LaunchPad MRECW database schema for Supabase (PostgreSQL).
-- Run this file in the Supabase SQL Editor for a new project.

create table if not exists public.startups (
  id bigint generated by default as identity primary key,
  founder_id uuid not null references auth.users (id) on delete cascade,
  name text not null check (char_length(btrim(name)) between 1 and 100),
  team_name text not null check (char_length(btrim(team_name)) between 1 and 100),
  tagline text not null check (char_length(btrim(tagline)) between 1 and 300),
  category text not null check (
    category in (
      'ai',
      'agritech',
      'edtech',
      'healthtech',
      'fintech',
      'sustainability',
      'ecommerce',
      'robotics'
    )
  ),
  department text not null check (
    department in ('CSE - AI & ML', 'CSE', 'Data Science', 'IT', 'ECE', 'EEE')
  ),
  looking_for text not null check (char_length(btrim(looking_for)) between 1 and 150),
  founder_name text not null check (char_length(btrim(founder_name)) between 1 and 100),
  founder_major text not null default 'MRECW Student'
    check (char_length(btrim(founder_major)) between 1 and 100),
  founder_avatar text not null default ''
    check (char_length(founder_avatar) <= 2048),
  banner text not null default ''
    check (char_length(banner) <= 2048),
  stage text not null default 'Prototype'
    check (stage in ('Idea', 'Prototype', 'MVP', 'Testing', 'Launch')),
  problem text not null default 'Student venture submitted by an MRECW team.'
    check (char_length(btrim(problem)) between 1 and 2000),
  description text not null default 'A student-led venture from MRECW.'
    check (char_length(btrim(description)) between 1 and 5000),
  created_at timestamptz not null default now()
);

create table if not exists public.applications (
  id bigint generated by default as identity primary key,
  startup_id bigint not null
    references public.startups (id) on delete cascade,
  applicant_id uuid not null references auth.users (id) on delete cascade,
  applicant_name text not null
    check (char_length(btrim(applicant_name)) between 1 and 100),
  email text not null
    check (
      char_length(btrim(email)) between 3 and 254
      and btrim(email) ~ '^[^[:space:]@]+@[^[:space:]@]+\.[^[:space:]@]+$'
    ),
  message text not null
    check (char_length(btrim(message)) between 1 and 1000),
  created_at timestamptz not null default now()
);

-- Add ownership columns when upgrading a database created from the earlier
-- LaunchPad schema. Legacy rows remain ownerless until intentionally migrated.
alter table public.startups
  add column if not exists founder_id uuid references auth.users (id) on delete cascade;

alter table public.applications
  add column if not exists applicant_id uuid references auth.users (id) on delete cascade;

create index if not exists idx_startups_category
  on public.startups (category);

create index if not exists idx_startups_department
  on public.startups (department);

create index if not exists idx_applications_startup
  on public.applications (startup_id);

create unique index if not exists idx_applications_startup_applicant_unique
  on public.applications (startup_id, applicant_id);

alter table public.startups enable row level security;
alter table public.applications enable row level security;

grant usage on schema public to anon, authenticated;
revoke all on public.startups from anon, authenticated;
revoke all on public.applications from anon, authenticated;
revoke all on sequence public.startups_id_seq, public.applications_id_seq from anon, authenticated;
grant select on public.startups to anon, authenticated;
grant insert, update, delete on public.startups to authenticated;
grant insert on public.applications to authenticated;
grant usage, select on sequence public.startups_id_seq, public.applications_id_seq to authenticated;

drop policy if exists "Anyone can view startups" on public.startups;
create policy "Anyone can view startups"
  on public.startups
  for select
  to anon, authenticated
  using (true);

drop policy if exists "Authenticated users can create startups" on public.startups;
create policy "Authenticated users can create startups"
  on public.startups
  for insert
  to authenticated
  with check (founder_id = (select auth.uid()));

drop policy if exists "Authenticated users can update startups" on public.startups;
create policy "Authenticated users can update startups"
  on public.startups
  for update
  to authenticated
  using (founder_id = (select auth.uid()))
  with check (founder_id = (select auth.uid()));

drop policy if exists "Authenticated users can delete startups" on public.startups;
create policy "Authenticated users can delete startups"
  on public.startups
  for delete
  to authenticated
  using (founder_id = (select auth.uid()));

drop policy if exists "Authenticated users can submit applications" on public.applications;
create policy "Authenticated users can submit applications"
  on public.applications
  for insert
  to authenticated
  with check (applicant_id = (select auth.uid()));

# Supabase setup

The Supabase folder is a set of database setup files; creating a Supabase account does not create these files in your repository. `schema.sql` defines the PostgreSQL tables, constraints, indexes, and Row Level Security (RLS) policies for LaunchPad MRECW.

## Apply the schema

1. Create a Supabase project and open its **SQL Editor**.
2. Open `supabase/schema.sql` from this repository, copy its contents into a new SQL query, and run it.
3. In **Table Editor**, confirm that `startups` and `applications` were created.
4. In **Authentication → URL Configuration**, set the site URL to your deployed website URL and add its URL to the redirect allow list.

The schema allows anyone to read startup listings. Creating, updating, or deleting a startup is limited to its authenticated founder. Submitting an application requires authentication and associates it with the authenticated applicant. Application records have no client-readable policy or table grant because they contain names, email addresses, and messages.

## Connect the Python API

1. Copy `backend/.env.example` to `backend/.env`. This private file is ignored by Git.
2. In the Supabase dashboard, open **Connect** and copy the PostgreSQL connection string. Use the session pooler if the direct connection is unavailable.
3. Set `DATABASE_URL` in `backend/.env` to that private connection string.
4. In **Project Settings → API**, copy the **Project URL** and public **anon** or **publishable** key. Set these as `SUPABASE_URL` and `SUPABASE_ANON_KEY` in `backend/.env`.
5. Set the same Project URL and public anon/publishable key in `frontend/js/supabase-config.js`; the browser uses them only for Supabase Auth.
6. Install backend dependencies from the project root using `python -m pip install -r backend\requirements.txt`, then restart the Python server.
7. Create an account, confirm the email if Supabase requests it, and sign in. The frontend sends the access token to the Python API; the API verifies it with Supabase Auth and uses PostgreSQL for startup/application operations.

When `DATABASE_URL` is set, the backend uses PostgreSQL and checks that the schema exists. When it is blank, the local SQLite database remains active. The Python API sets the verified user's PostgreSQL request role and user ID so the schema's RLS policies are enforced. Startup changes are founder-scoped; each applicant can submit one application per startup. Application rows are not readable through the client API.

The Project URL and public anon/publishable key are safe for the browser; RLS remains essential. **Never put the PostgreSQL connection string, database password, `service_role` key, or any secret key in frontend code or GitHub.**

The schema does not insert demo records. Existing SQLite records remain in `launchpad.db` and are not uploaded automatically. Export/import only records you intend to move; each startup needs a valid `founder_id` for a Supabase Auth user. The deployed website must use HTTPS and its exact origin must be allowed in Supabase Auth URL settings.
